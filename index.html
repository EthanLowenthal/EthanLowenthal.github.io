I'm a software engineer with a strong background in mathematics and computer science. At Ayar Labs, I build photonics infrastructure to enable faster, more advanced tapeouts. Previously, at PsiQuantum, I built software systems that support the manufacturing of ultra-low-loss silicon photonic chips for photonic quantum computing.

  • Photonics Infrastructure @ Ayar Labs: Building infrastructure for photonic design automation, using tools such as GDSFactory, to accelerate and scale tapeout workflows for TeraPHY chips.
  • Fiber Array Alignment @ PsiQuantum: Wrote the search algorithm for automated photonic fiber-array and heterogeneous die-to-die alignment using nanometer-precision motion control. Scaled the process for high-volume semiconductor manufacturing through successful OSAT technology transfer, achieving worlds best edge-coupling performance.
  • OceanEye @ University of Victoria: A Qt/C++ desktop application for efficient image and video annotation supporting human-in-the-loop computer vision workflows; accompanying paper accepted for publication in an IEEE conference proceedings.
  • Open Source Contributions: Author of GDS Lens, a VS Code extension that renders GDSII and OASIS chip layouts in a WebGL2 canvas. Contributed to various open source projects, including the ShaderToy-Chrome-Plugin and LabExT, open-source projects focused on shader development tooling and automated control of photonic laboratory experiments.
